# Transformer-Analysis-Tool

Transformer Analysis software I developed for my Electrical Machines course.

## About the Project
I am currently taking the **Electrical Machines I** course at **Düzce University**. While studying Single-Phase Transformers, I wanted to visualize the formulas we learned in class instead of just solving them on paper.I wrote this simple desktop app using **Python**. It helps to understand how efficiency and voltage regulation change under different loads.
### Key Features
*   **Lab Mode:** You can enter Open Circuit & Short Circuit test data, and it calculates the parameters (Req, Xeq) automatically.
*   **Visualization:** It plots the **Efficiency** and **Voltage Regulation** curves.
*   **Simulation:** You can play with Power Factor (cos φ) using a slider to see real-time effects.
> **Note:** This is a work in progress. As we cover new topics in class, I will continue to develop this project.
